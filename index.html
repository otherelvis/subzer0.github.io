BAYESIAN HYBRID MODELS

I conceptualized and implement a novel framework to enable decision-making under uncertainty with physics-informed machine learning using Bayesian hybrid models. These models can learn unknown process dynamics directly from (historical) data and propose optimized system designs. You can read about this work in the paper titled Learning and optimization under epistemic uncertainty with Bayesian hybrid models.
